# Зерно — интернет-магазин кофе на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина кофе свежей обжарки «Зерно», разработанную с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- Bootstrap-навигация `navbar`;
- hero-блок на сетке `row` / `col-12 col-lg-6`;
- блок преимуществ `col-12 col-md-6 col-lg-3`;
- сетка популярных товаров на карточках `card`;
- подвал страницы.

## Используемые технологии

- HTML;
- Bootstrap 5.3.8;
- CSS;
- Git;
- GitHub.
