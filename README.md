# Зерно — интернет-магазин кофе на Bootstrap

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Учебная версия сайта интернет-магазина кофе свежей обжарки «Зерно», разработанная с использованием Bootstrap.
Это отдельная реализация той же предметной области, что и в КР №1 (не адаптация КР №1):
главная страница, каталог, страница товара, оформление заказа и контакты.

## Ссылка на опубликованный проект

GitHub Pages: https://kikimor0607.github.io/kr2-bootstrap-shop/

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `head`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается перед `</body>`, нужен для `navbar` (мобильное меню), `modal`, `accordion`, `carousel`, `tabs`, `toast`, `collapse`.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы переопределять его стили:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

## Bootstrap-сетка

- `container` — центрирует контент и ограничивает ширину;
- `row` + `col-*` — 12-колоночная сетка;
- адаптивные колонки: `col-12 col-md-6 col-lg-4` (карточки), `col-12 col-lg-6` (hero, товар), `col-12 col-lg-3` + `col-12 col-lg-9` (каталог), `col-12 col-lg-8` + `col-12 col-lg-4` (заказ);
- отступы между колонками: `g-4`, `g-lg-5`, `g-3` (формы).

## Реализованные компоненты

Обязательные:

- `navbar` — на всех страницах, мобильное меню раскрывается кнопкой;
- `card` — карточки товаров, преимуществ, контактов, состав заказа;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-link`, размеры `btn-lg`, `btn-sm`, свой вариант `btn-accent`;
- `badge` — «Хит», «Новинка», «−16%», «Нет в наличии», счётчик корзины, количество товаров;
- `alert` — информационные сообщения, закрываемый промо-alert, сообщения об успешной отправке форм;
- `modal` — «Быстрая заявка» на всех страницах;
- `form-control`, `form-select`, `input-group` (`+7`, `@`, `шт.`, промокод), `form-check` (чекбоксы, radio, switch);
- `accordion` — частые вопросы на странице заказа.

Дополнительные:

- `carousel` — отзывы на главной и галерея товара;
- `tabs` (`nav-tabs` + `tab-content`) — описание / характеристики / как заварить;
- `toast` — уведомление «Товар добавлен в корзину»;
- `pagination` — страницы каталога;
- `breadcrumb` — хлебные крошки на внутренних страницах;
- `collapse` — фильтры каталога сворачиваются на мобильных;
- `list-group`, `progress`, `table` (`table-striped`, `table-hover`), `btn-group` + `btn-check`, `form-range`.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` — сайт работает без интернета.
2. **Дополнительная страница `contacts.html`** — контакты и форма обратной связи.
3. **Дополнительные компоненты** — `carousel`, `tabs`, `toast`, `pagination`, `breadcrumb`, `collapse`.
4. **Улучшенный каталог** — боковая панель фильтров (категории со счётчиками, тип обжарки, цена `form-range`, переключатель «Только в наличии»), сортировка, на телефоне фильтры прячутся под кнопку «Показать фильтры».
5. **Улучшенные карточки** — бейджи, старая цена у скидки, неактивная кнопка и серое фото у товара «Нет в наличии», кнопка «В корзину» с уведомлением.
6. **Сценарий заказа** — прогресс оформления, выбор помола и количества, состав заказа с итоговой суммой и промокодом, проверка полей с подсказками (`was-validated`, `invalid-feedback`) и сообщение об успешной отправке.
7. **Собственный стиль через `custom.css`** — «кофейная» палитра через переопределение CSS-переменных компонентов Bootstrap (`--bs-btn-*`, `--bs-pagination-*`, `--bs-accordion-*`), без копирования стилей Bootstrap.
8. **Адаптивность** — проверены ширины 375 px (телефон), 768 px (планшет) и 1366 px (ноутбук).
9. **Доступность** — `label` у всех полей, `aria-label` у кнопок без текста, `aria-current` в меню и хлебных крошках, `visually-hidden` подписи у стрелок карусели, `prefers-reduced-motion`.

## Как проверить

- Меню: сузить окно до телефона → нажать кнопку меню.
- Модальное окно: «Быстрая заявка» в шапке или «Заказать» на карточке.
- Валидация: нажать «Отправить» с пустой формой → поля подсветятся, затем заполнить → появится зелёный alert.
- Toast: кнопка 🛒 на карточке или «В корзину» на странице товара.
- Вкладки и галерея: `product.html`. Accordion: `order.html`. Карусель отзывов: `index.html`.
